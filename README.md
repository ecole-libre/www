# Mon école libre — site vitrine

Site statique publié par GitHub Pages sur https://monecolelibre.fr (branche `main`, racine du dépôt).

- `index.html` : la page, autonome (styles, images et script inclus).
- `fonts/` : Inter et Caveat servies par le site (pas de Google Fonts).
- `CNAME` : le domaine déclaré à GitHub Pages.

Voir en local : ouvrir `index.html` dans un navigateur, ou `npx serve .`.
